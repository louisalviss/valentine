# Native Content reconstruction

Reference: https://www.nativecontent.com/

This candidate is an independent render-equivalent reconstruction for `VALENTINE-HARVEST-001`.

## What is reproduced

- nine viewport-height project sections;
- fixed top navigation and bottom social navigation;
- active project label changes at section boundaries;
- desktop left/right project/director typography placement;
- mobile centered stacked project/director placement;
- mobile full-screen menu interaction and Escape close;
- responsive page rhythm at 390x844, 768x1024, and 1440x900.

## What is deliberately not copied

- Native Content authored JavaScript/Next.js bundles;
- Mux playback IDs or video streams;
- site font files;
- commercial project footage, posters, stills, or client media.

The background scenes are local CSS-generated abstractions whose purpose is to preserve composition, tonal rhythm, and self-contained rendering without asserting reuse rights over the source media.

## Fidelity policy

Commercial project media is a rights-constrained surface. Full-frame screenshot metrics must remain visible, but the candidate must be evaluated primarily on independently reproducible layout/geometry, typography placement, section sequencing, navigation, scroll-state behavior, and menu interaction. Any rights exception must be explicit in the manifest/report and must never be presented as pixel-identical media reproduction.
