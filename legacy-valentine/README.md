# Legacy repository origin

This repository originally started from the open-source **Will You Be My Valentine?** project by `ivysone` and used its MIT-licensed root files as the initial repository base.

The active root is now a Web Experience Lab, so the old Valentine page is no longer kept in the working tree. Its complete historical files remain available in git history, and the original MIT license notice remains at the repository root.

When reconstructing or redistributing the original project, preserve the original copyright and MIT license notice.
